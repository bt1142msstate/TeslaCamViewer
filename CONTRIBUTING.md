# Contributing

Thanks for helping improve TESLA Cam. This repository is source-available, not
open source, so contributions need to follow the project license.

## Ground Rules

- Do not include private TeslaCam footage, GPS traces, license plates, faces, or
  other personal data in issues, screenshots, tests, or pull requests.
- Keep changes focused and explain the user-facing behavior they affect.
- Include screenshots for visual/UI changes when practical.
- Include local build or test notes in pull requests.
- Avoid adding cloud uploads, analytics, telemetry collection, or account
  integrations without a privacy review.
