Source-available Windows TeslaCam viewer

TESLA Cam

Turn split TeslaCam files into continuous drive sessions with synchronized camera views, telemetry, markers, and export tools.

Download preview View source Install notes

Built For Drive Review

Stitched Playback

Groups one-minute TeslaCam files into full drive sessions and plays each camera as a continuous timeline.

Telemetry HUD

Displays embedded speed, steering, gear, pedal, blinker, GPS, heading, and autonomy data when available.

Markers And Export

Add IN and OUT markers, then export the current view or all views with post-export telemetry validation.

GitHub Install Preview

The long-term command-line install path is WinGet after the final package name, signing, and package identity are ready. Preview builds are available from GitHub Releases.

powershell -ExecutionPolicy Bypass -File .\Install-TESLA-Cam.ps1 -ReleaseTag v0.1.0-preview.1
